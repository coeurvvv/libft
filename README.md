## Description ##
This project is the creation of a library.

**Libft** is a library of functions in three parts:
- a set of libc functions
- additional functions with a set of rules
- functions implementing structures and linked lists

### Why ###
Creating this library results in an understanding of C fundamentals.
This library will be used in future projects during the curriculum.

## Instructions ##
### Usage ###
```
git clone
cd libft
make
```

Creates `libft.a` in the root directory.

The Makefile contains a set of commands: `make clean`, `make fclean` and `make re`.
